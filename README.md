# DonationRaid — релизы

Локальный интерактивный рейд для OBS, реагирующий на донаты DonationAlerts.

[Посмотреть демонстрацию на YouTube](https://www.youtube.com/watch?v=zpCS10SDves).

В этом репозитории публикуются готовые выпуски для Windows. Файлы программы приложены к каждому выпуску в разделе [Releases](https://github.com/RaniNamari/DonationRaid-releases/releases).

## Скачать и запустить

1. Открой [последний релиз](https://github.com/RaniNamari/DonationRaid-releases/releases/latest) и скачай `DonationRaid-1.0.3.zip` из раздела Assets. Автоматические архивы `Source code` содержат только описание этого репозитория.
2. Распакуй архив целиком в отдельную папку.
3. Настрой цель и остальные параметры в `streamer_config.js`.
4. Запусти `START.cmd` и при первом запуске войди в DonationAlerts через открывшийся браузер.
5. Добавь в OBS источник «Браузер» с адресом `http://127.0.0.1:17321/` и размером 2560 × 1440.
6. Оставляй окно запускатора открытым во время трансляции.

Подробная инструкция находится в `README.txt` внутри архива. Токены и ключи в конфиг вводить не нужно. Прогресс рейда сохраняется в `streamer_config.js`; перед обновлением сохрани этот файл и перенеси свои настройки в новую папку.

## Проверка загрузки

К релизу приложен `sha256.txt`. В PowerShell проверь архив командой `Get-FileHash .\DonationRaid-1.0.3.zip -Algorithm SHA256` и сравни результат с указанной контрольной суммой.
